01 / PURPOSE

Pixel-art exploration game

Build a relaxing game around exploration, collecting, and decorating rather than combat.

02 / FUNCTIONALITY

What the application does

  • Choose a bunny character, a colour, and a name, with a save system for player progress.
  • Explore a scrollable home garden with multiple themes, farm plots, pets, and a house area.
  • Place decorations and collect carrots within a pixel-art world.

03 / IMPLEMENTATION

Technical approach

Vue, TypeScript, and Ionic form the application shell. Phaser 3 handles the 2D game experience, while pixel-art assets define the characters, garden, and decorations.

VueTypeScriptPhaser 3Ionic

04 / SCOPE

Project status

In active development. The project explores how a component-based application can host an interactive game world.
