PROJECT OVERVIEW

PurposeFunctionalityTechnical approachScope & status

01 / PURPOSE

Mobile budgeting application

Help people understand their monthly budget and available spending money through a mobile-first interface.

02 / FUNCTIONALITY

What the application does

  • View monthly balance, income, spending, and savings-goal progress.
  • Search transactions by category and remove entries with swipe-to-delete.
  • Compare planned and actual spending per category.
  • Configure salary, savings goals, and a custom budget-month start day.

03 / IMPLEMENTATION

Technical approach

Built with Vue 3, TypeScript, Ionic Vue, and Vue Router. The interface is organised around budget periods, transactions, categories, and settings.

Vue 3TypeScriptIonic

04 / SCOPE

Project status

A mobile-first budgeting project. Its local repository is named velora; the product is presented as Monvex.
