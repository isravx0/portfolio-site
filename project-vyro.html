PurposeFunctionalityTechnical approachScope & status

01 / PURPOSE

Offline workout journal

Make workout planning, session logging, and reviewing progress available in one application, including when there is no connection.

02 / FUNCTIONALITY

What the application does

  • Build and reorder routines using a searchable exercise catalog with muscle and equipment filters.
  • Plan recurring weeks and dated sessions, with rest days and explicit links between planned and completed workouts.
  • Log weighted, bodyweight, and timed exercises. Active sessions support pause, resume, rest timers, and recovery after reload.
  • Review completed sessions, monthly totals, training volume, and heaviest recorded sets. Export data as versioned JSON.

03 / IMPLEMENTATION

Technical approach

Vue and Ionic provide the interface; Capacitor supports the mobile application structure. IndexedDB stores data locally with serialized writes and revision checks. Completed sessions retain their own snapshots so later routine edits do not change workout history.

VueIonicCapacitorIndexedDB

04 / SCOPE

Project status

The web app includes an app-shell service worker for offline reload after the first online visit. Native device behavior is not verified by the web build; cloud sync and backup import remain outside v1.
