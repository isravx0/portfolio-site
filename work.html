CASE STUDY 01

Monvex — Personal Budgeting

A mobile and web budgeting application for understanding your balance, tracking transactions, and planning ahead.

Purpose

Understand what is available to spend and compare planned and actual spending across budget periods.

Technical approach

Vue 3 and Vite power the web application. The mobile version uses Ionic and TypeScript, with views for transactions, budgets, and savings goals.

Key features

  • Income and expense tracking
  • Monthly budget periods
  • Savings goals and category budgets
  • Twelve-month budget forecast on web

CASE STUDY 03

Solar Panel Simulator

A data-focused full-stack tool that translates technical inputs into understandable estimates and visual summaries.

Challenge

Solar calculations involve technical assumptions and multiple variables. The result needed to remain understandable for non-technical users.

Approach

The flow connects user inputs, calculation logic, monthly output data, and a visual summary that highlights the main result first.

Key features

  • Input-based estimation
  • Monthly output charts
  • Consumption comparison
  • CSV export
